# 车辆管家婆 · 手机端演示

状态：🟢 商业试运营（演示版）｜ 形态：移动端网页 ｜ 数据：虚构演示数据

## 这是什么

面向门店手机使用的进销存与客户跟进界面：一屏查看在库车辆、待跟进客户与今日经营概览。
本仓库只做界面与交互演示，**不连接生产环境，不含真实客户资料**。

## 主要能力

- 车辆台账：在库 / 已售 / 预订状态一览
- 客户跟进：意向、回访与成交节点
- 经营概览：今日新增、待办与库存结构
- 车架号横向扫描识别，一车多图（封面 / 追加 / 删除）

## 浏览方式

用手机浏览器打开仓库内 `index.html`，或本地起一个静态服务。

## 版本与变更

当前版本 **v3.2.0**（版本与说明见 `version.json`），主要变化：一车最多 6 张照片、
双指缩放看图、逐张上传进度、车架号扫描；客户、销售、分期、收款与欠款功能不变。

## 边界与声明

- 演示数据均为虚构，与真实门店、客户无关。
- 不含账号凭据与内部部署信息，不构成生产系统。
